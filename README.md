# PuzzleTogether

**Free online multiplayer jigsaw puzzles** — no download, play together in the browser.

Invite friends with a link and solve the same board on phone or PC.

**Website:** [https://www.puzzletogether.net](https://www.puzzletogether.net)

## Features

- Cooperative multiplayer jigsaw in the browser
- Share an invite link — no app install
- Public rooms or private invites
- Works on phone and desktop

## Play now

Open **[puzzletogether.net](https://www.puzzletogether.net)** and start a puzzle, or join a public room.
